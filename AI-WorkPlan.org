* Stage 2: Package Status --- Reinstall, Push and Update Detection

<<Stage 2>>

Goal: read-only commands that tell, for one bisos-pip package or all of them, which of three
actions it needs:
- *reinstall* --- the repo is ahead of its editable install in =/bisos/venv/py3/dev-bisos3=;
- *push* --- the repo (committed and pushed) is ahead of what was uploaded to PyPI;
- *update* --- PyPI is ahead of =/bisos/venv/py3/bisos3=.

Decided in =bisos-pip/overview= WorkPlan 4.1 (2026-11-15; the analysis is in its Results): the
commands go here, beside =pyPkgTools.cs=, so that a =pipx install bisos.pycs= is enough (no full
BISOS). No git tags: contents are compared, not versions (local versions are always 0.1).

The checks:
- reinstall: (1) =.dist-info/direct_url.json= is editable and points to this repo's =py3=;
  (2) =py3/bin= vs. =setup.py='s =scripts= (differ: regenerate =setup.py= first); (3) =scripts= vs.
  the =/bisos/venv/py3/devbin= symlinks (=seedPypiProc.sh='s =vis_devBinSymlinks=), none dangling;
  (4) =setup.py= / =pyproject.toml= newer than the install's =.dist-info=, and =pip check=.
- push: the repo's package and =bin/= files vs. the sha256s in bisos3's =.dist-info/RECORD=;
  uncommitted or unpushed work is reported as such, not as a push.
- update: PyPI's latest version (=pypiLatestVersion=) vs. bisos3's installed version.
